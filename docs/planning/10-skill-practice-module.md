## 3. IELTS Reading Practice

### 3.1 Fourteen Question Types

Each type has its own dedicated drill set, available at multiple CEFR levels.

| # | Question Type | Description |
| :---: | :--- | :--- |
| 1 | Multiple Choice (single answer) | Choose 1 from A, B, C, D |
| 2 | Multiple Choice (multiple answers) | Choose 2–3 correct answers from a list |
| 3 | True / False / Not Given | Factual claims about the text |
| 4 | Yes / No / Not Given | Writer's views and claims |
| 5 | Matching Headings | Match headings to paragraphs |
| 6 | Matching Information | Locate specific information in paragraphs |
| 7 | Matching Features | Match items to a list of options |
| 8 | Matching Sentence Endings | Complete sentences by selecting the correct ending |
| 9 | Sentence Completion | Fill blank with words directly from the text |
| 10 | Summary Completion | Complete a paragraph summary from the text |
| 11 | Note / Table / Flow-chart Completion | Fill structured notes/tables from text |
| 12 | Diagram Label Completion | Label parts of a diagram using text information |
| 13 | Short Answer Questions | Answer in no more than 3 words from text |
| 14 | Identifying the Writer's Views | Identify if a statement agrees with the writer |

### 3.2 CEFR Levels per Drill Set

| Level | Passage Length | Vocabulary | IELTS Band Target |
| :--- | :---: | :--- | :---: |
| Level 1 (A2–B1) | 200–350 words | Common, accessible | Band 4–5 |
| Level 2 (B1–B2) | 400–550 words | Mixed academic | Band 5–6 |
| Level 3 (B2–C1) | 600–800 words | Full academic | Band 6–7.5 |
| Level 4 (C1–C2) | 750–900 words | Dense, abstract | Band 7.5–9 |

### 3.4 Academic vs General Training Format

- **Academic:** Dense, complex, abstract texts (for university entrance and professional immigration visas)
- **General Training:** Workplace notices, advertisements, practical letters, less academic vocabulary (for work visa and migration)

## 5. IELTS Writing Practice

### 5.1 Task 1 Academic — Seven Chart / Diagram Types

| Type | Description |
| :--- | :--- |
| Bar Chart | Static or grouped bars comparing categories across time or groups |
| Line Graph | Trends over time for one or more variables |
| Pie Chart | Proportional data — often 2 pies compared |
| Table | Numerical data in rows and columns |
| Process Diagram | Linear or cyclical process (manufacturing, natural cycle) |
| Maps | Before and after comparison of a geographical area |
| Mixed Visuals | Combination of 2 chart types (e.g., bar + pie) |

### 5.2 Task 1 General Training — Three Letter Types

| Type | Examples |
| :--- | :--- |
| Formal Letter | Complaint to a company, application letter, letter to an authority |
| Semi-Formal Letter | Letter to a neighbour, a teacher, or an acquaintance |
| Informal Letter | Letter to a friend requesting help, sharing news, making plans |

### 5.3 Task 2 — Five Essay Types

| Type | Structure |
| :--- | :--- |
| Opinion (Agree / Disagree) | State and justify a clear position |
| Discussion (Two Views) | Discuss both sides + your opinion |
| Problem and Solution | Identify the problem + propose solutions |
| Advantage / Disadvantage | Evaluate pros and cons |
| Combined / Two-Part Question | Answer two specific sub-questions in the prompt |

### 5.4 Scoring

- **Unscored mode (free):** User writes, sees a model answer, self-evaluates with a rubric checklist
- **AI-scored mode (80 Sparks or Premium):** Gemini evaluates using all 4 official IELTS criteria:
  - Task Achievement / Response
  - Coherence and Cohesion
  - Lexical Resource
  - Grammatical Range and Accuracy

### 5.5 Timed Writing Mode

- Task 1: strict 20-minute countdown (real IELTS time allocation)
- Task 2: strict 40-minute countdown
- Visible timer on screen — cannot pause
- After submission, AI scoring is immediately available

## 6. IELTS Speaking Practice

### 6.1 Part 1 — Personal Questions

- 8–10 quick questions on familiar topics
- User records a 30–60 second audio response per question
- **Unscored mode (free):** user records, hears playback, sees model answer
- **AI-scored mode (60 Sparks or Premium):** pronunciation feedback, fluency estimate, vocabulary range

**Topics pool (30+):** Hometown, Home, Work/Study, Hobbies, Food, Sport, Music, Weather, Travel, Shopping, Technology, Social Media, Books, Environment, Family, Friends, Art, Mornings, Evenings, Weekends, Cooking, Fashion, Pets, Transport, Gardens, Learning, Languages, Memory, Health, Sleep

### 6.2 Part 2 — Cue Card (Long Turn)

- User receives a cue card with a topic + 3–4 bullet points
- 1 minute preparation time shown on screen
- 2 minutes to speak (auto-stops recording)
- **Unscored mode (free):** record and self-review + model answer
- **AI-scored (60 Sparks or Premium):** full 4-criterion scoring

**Cue card bank (100+ cards) organized by category:**

| Category | Example Prompt |
| :--- | :--- |
| People | Describe a person who has influenced you |
| Places | Describe a place you visited that disappointed you |
| Objects | Describe a gift you received that was meaningful |
| Events | Describe a celebration or festival you attended |
| Experiences | Describe a time you had to make a difficult decision |
| Abstract | Describe a skill you would like to learn in the future |

### 6.3 Part 3 — Discussion Questions

- 5–6 abstract follow-up questions linked to the Part 2 topic
- Requires extended, complex answers (2–3 minutes per question)
- Always AI-scored (60 Sparks or Premium) — Part 3 is too abstract for unscored self-review to be useful

### 6.4 Full Speaking Simulation

- All 3 parts in sequence
- AI scored end-to-end
- Total speaking time: ~14–15 minutes
- Full report: band score per criterion + specific improvement tips per criterion

## 8. Vocabulary Drills

### 8.1 Academic Word List (AWL) — Groups 1–10

- Coxhead's Academic Word List: 570 word families organized in 10 sublists by frequency
- Each group: ~57 word families
- Drill types: definition matching, gap fill in context sentence, synonym identification, academic vs informal register distinction
- Progress tracked: how many AWL words are "mastered" (correctly answered 3+ times across spaced sessions)

### 8.2 Topic Vocabulary Sets (same 15 topics as Reading)

For each topic: 40–60 high-frequency IELTS vocabulary items including:
- Nouns, verbs, adjectives, adverbs most likely to appear in that topic's texts
- Key collocations (verb + noun, adjective + noun pairs)
- Example sentences from real or near-real IELTS passages

### 8.3 Collocations Drills

- "Make" vs "Do" (make a decision / do research)
- Environment collocations (global warming, carbon emissions, renewable energy, carbon footprint)
- Health collocations (maintain health, adopt a lifestyle, develop a condition, fight a disease)
- Business collocations (run a company, meet a deadline, cut costs, boost revenue)
- Education collocations (pursue a degree, broaden horizons, bridge the skills gap)

### 8.4 Phrasal Verbs in Academic Context

- Phrasal verbs that are acceptable in semi-formal writing (carry out, look into, come up with, point out)
- Phrasal verbs to avoid in formal writing + formal equivalents
- Gap fill and MCQ exercises in academic paragraph contexts

### 8.5 Synonyms and Paraphrasing

This is a critical IELTS skill (used in every section):
- See a word → choose 3 correct synonyms from 6 options
- See a sentence → choose the correct paraphrase from 4 options
- Rewrite a sentence using a given key word (productive vocabulary)
- Identify which synonym fits academic register vs informal register (e.g., "kids" vs "children" vs "minors")

## 9. Smart Practice (AI-Personalized)

### 9.1 Weak Area Focus

The system analyzes the user's CEFR Mastery Profile (updated after every activity) and identifies the 3 lowest-scoring skill dimensions.

Example: *"Your Reading T/F/NG accuracy is 54%. Your Grammar Passive Voice score is 61%. Your Vocabulary (AWL Group 3) accuracy is 58%. Here are today's recommended sets:"*

### 9.2 Daily Recommended Set

- Auto-generated each day: 3 drill sets covering the 3 weakest areas
- Takes ~10–15 minutes total
- Completing the full recommended set earns a bonus:
  - +20 Sparks
  - +1 Focus
  - Counts toward "Smart Learner" achievement

### 9.3 Timed Challenge Mode

- 20 mixed random questions from across all skill areas
- 20-second timer per question
- No Focus cost — this mode is always available
- Score submitted to a daily global leaderboard (within your league)
- Top 10% earn +30 bonus Sparks
- Questions become harder as your accuracy improves (adaptive difficulty within a session)
