# 08 — Character System

---

## 1. Purpose

The character system serves three goals:

1. **Sparks sink** — gives users a meaningful place to spend accumulated Sparks beyond AI features
2. **Emotional investment** — a personalized avatar makes users feel ownership and identity within the platform
3. **Social display** — characters are visible on leaderboards, profiles, and achievement animations, creating aspirational display

The character is woven into the entire experience. Users see their character constantly — not just in a settings menu.

Each character has 8 customization slots. Items are purchased individually and are cross-character (equippable on any character you own).

| Slot | Item Examples |

| **Body / Outfit** | School uniform, explorer vest, business suit, hoodie, traditional áo dài, kimono, lab coat, sports kit |
| **Hand / Item** | Open book, fountain pen, shield (dictionary cover), globe, phone, trophy, sword (quill), lantern |
| **Badge / Pin** | Country flag pins, IELTS band icons, achievement badges pinned to outfit, custom emoji pins |
| **Background / Card** | Library interior, ancient temple, outer space, bamboo forest, starry night, city skyline, snowy mountain |
| **Aura / Effect** | Streak flame aura, star sparkle (top learner), ice glow, golden shower, lightning crackle, rainbow mist |

## 5. Sparks Shop

A dedicated in-app shop where users browse and purchase characters, items, and utility upgrades.

### Shop Features
- Browse by slot type, rarity, or character
- Preview any item on your character before purchasing
- **Daily Deal**: one randomly selected item at 30% discount, refreshes every 24 hours
- **New Arrivals**: items added in the last 7 days highlighted
- **Seasonal Section**: limited-edition items available during events
- Filter by: "Can afford" (only show items within your Sparks balance)

### Utility Purchases in Shop (non-cosmetic)
| Item | Cost |
| :--- | :---: |
| Streak Freeze | 50 Sparks (max 3 in stock) |
| Extra flashcard slots today (+50) | 80 Sparks |
| Focus refill (+5 units) | 30 Sparks |

## 6. Where the Character Appears

The character is integrated into the entire product experience. Users see it constantly.

| Location | How the Character Appears |
| :--- | :--- |
| **Home screen** | Character displayed prominently with equipped items, current title, streak flame, Sparks balance |
| **Profile card** | Full character display with equipped cosmetics, league badge, title |
| **Leaderboard** | Small animated character icon beside each user's entry |
| **Achievement unlock** | Full-screen animation: character celebrates with particle effects matching the achievement theme |
| **Daily challenge complete (all 3)** | Character does a victory pose + Sparks shower animation |
| **Streak milestone** | Character gets the appropriate aura effect (e.g., gold flame at 30 days) |
| **League promotion** | Cinematic cutscene: character walks into a new arena environment matching the new league |
| **Login screen** | Character greets user with a contextual animation (morning coffee cup, streak day = flame effect) |
| **Minigame avatar** | Character is the player avatar in all PVP and solo games |
| **Victory / defeat screen** | Character celebrates (win) or slumps (lose) after a game |
| **Sparks earned popup** | Sparks burst from the character's hands |
| **Item unlock** | Item physically "equips" onto the character with an animation |
| **Focus bar empty** | Character sits down and looks tired |
| **Focus bar full** | Character stands energetically, small sparkle effect |
| **Daily check-in** | Character waves and "hands over" the daily Sparks reward |
| **Secret achievement unlock** | Character looks surprised, then excited, with a special reveal animation |

## 7. Seasonal and Cultural Characters / Items

To resonate with target markets (see [07-leaderboard-and-leagues.md](./07-leaderboard-and-leagues.md)), seasonal items are released for major cultural events:

| Event | Region | Example Items |
| :--- | :--- | :--- |
| Tết (Vietnamese New Year) | Vietnam | Áo dài outfit, red envelope accessory, peach blossom background |
| Diwali | India, South Asia | Diya lantern item, rangoli background, festive kurta outfit |
| Eid al-Fitr | Middle East, SE Asia | Crescent moon pin, traditional dishdasha/abaya outfit, lantern pet |
| Sakura Season | Japan, Korea | Cherry blossom background, kimono outfit, sakura petal aura |
| Mid-Autumn Festival | Vietnam, China, Korea | Moon lantern item, mooncake pin, autumn background |

These items are available **only during the event** and are never brought back, making them true collector's items.
